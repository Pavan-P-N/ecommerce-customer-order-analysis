# E-commerce Customer & Order Analysis

## Project Overview

This project explores the Brazilian E-Commerce Public Dataset by Olist. The aim is to analyse customer purchasing behaviour, product sales, order delivery performance, and customer reviews.

Using Python, Pandas, and SQL, I performed data cleaning, exploratory data analysis, and visualisation to identify useful patterns and insights.

## Tools and Technologies

- Python
- Pandas
- NumPy
- SQL (SQLite)
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The project uses the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) from Kaggle.

The dataset contains multiple CSV files covering customers, orders, products, sellers, payments, reviews, and other information.

**Note:** The dataset files are not included in this repository.

## How to Run the Project

1. Download the dataset from Kaggle using the link above.
2. Extract the downloaded files.
3. Upload the extracted dataset folder to your Google Drive.
4. Make sure the folder is named `archive (1)` and is located directly inside `MyDrive`, or update the `data_path` variable in the notebook to match your folder location.
5. Open the notebook in Google Colab.
6. Run the cells in order and grant Google Colab access to your Google Drive when prompted.

## Key Findings

- 96.88% of customers placed only one order, while 3.12% made repeat purchases.
- Health and Beauty was the highest-selling product category, followed by Watches and Gifts and Bed Bath Table.
- The average delivery time was approximately 12 days, with a median of 10 days.
- 57.78% of customer reviews received 5 stars, while 14.69% received 1 or 2 stars.
- November 2017 recorded the highest monthly product sales in the period examined.
